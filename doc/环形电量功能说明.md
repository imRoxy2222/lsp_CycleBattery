# ColorOS 17 环形电量模块 - 功能说明

## 功能概述

**隐藏系统电池图标（使用 ColorOS 自带设置，其他图标自动补位），并在前置摄像头切孔周围独立绘制一圈电量指示环。**

| 功能点 | 说明 | 配置键 |
| --- | --- | --- |
| 启用开关 | 关闭后自动移除悬浮窗 | `enabled` |
| 环外径 | 20 ~ 160 dp，圆心 = 摄像头切孔中心 | `size_dp` |
| 水平偏移 | -80 ~ 80 dp（右为正） | `offset_x_dp` |
| 垂直偏移 | -80 ~ 80 dp（下为正） | `offset_y_dp` |
| 线条粗细 | 1 ~ 10 dp | `stroke_width_dp` |
| 普通状态颜色 | 电量正常时 | `color_normal` |
| 充电状态颜色 | 插入充电器时 | `color_charging` |
| 低电量状态颜色 | 电量 ≤ 阈值时 | `color_low` |
| 低电量阈值 | 5% ~ 50% | `low_level_threshold` |

- **所有参数即时生效**（大小/位置/粗细/颜色），无需重启系统界面
- 电量与充电状态由系统广播 `ACTION_BATTERY_CHANGED` 驱动
- **横屏时不显示**电量环，竖屏自动恢复
- 电量环不响应触摸，不影响任何应用操作；其他应用的事件遮挡检测（`FLAG_WINDOW_IS_OBSCURED`）不会触发

### 手动输入

- **外观参数**（环外径/偏移/线宽/阈值）：每个滑条右侧配有数值输入框，直接键入精确值后按"完成"（IME Done）提交，超出范围自动截断到上下限；拖动滑条同样可用，两者保持同步
- **状态颜色**：每个颜色行右侧提供 Hex 输入框，支持三种格式——`34C759`、`#34C759`（不透明）以及 `FF34C759`（8 位 AARRGGBB 含透明度）；格式错误时红字提示且不写入；输入后按"完成"提交，与预设色板双向同步

## 技术实现

### 依赖与规范

- **libxposed API 102**（`io.github.libxposed:api:102.0.0`，compileOnly）：
  - 入口类注册于 `app/src/main/resources/META-INF/xposed/java_init.list`
  - 作用域静态锁定：`META-INF/xposed/scope.list` 仅含 `com.android.systemui`，且 `module.prop` 声明 `staticScope=true`，用户无法在 LSPosed 中勾选其他应用
- **配置同步**：`io.github.libxposed:service:102.0.0`（RemotePreferences）
  - 模块 App 端通过 `XposedServiceHelper` 连接框架服务后写入
  - SystemUI 进程内通过 `XposedModule.getRemotePreferences()` 只读，并注册监听器实时刷新

### 实现方式（v2：独立悬浮窗）

**不 hook 任何宿主（SystemUI）类**，因此不需要 DexKit，也不受宿主混淆影响：

1. **Hook 框架方法 `Instrumentation#callApplicationOnCreate`**（框架类永不混淆），
   在 SystemUI Application 创建完成后拿到上下文
2. **添加系统内部悬浮窗**：
   - 全屏透明（`MATCH_PARENT` + `PixelFormat.TRANSLUCENT`）、
     `NOT_TOUCHABLE | NOT_FOCUSABLE | HARDWARE_ACCELERATED | LAYOUT_IN_SCREEN | LAYOUT_NO_LIMITS`
   - 窗口类型 `TYPE_STATUS_BAR_SUB_PANEL`（反射读取，回退 `TYPE_APPLICATION_OVERLAY`）。
     由 SystemUI 进程添加（持有 `INTERNAL_SYSTEM_WINDOW` 权限），
     **不占用悬浮窗权限，不出现在"显示在应用上层"授权列表**
3. **`CameraRingView`（纯 Java）** 自绘电量环：
   - 圆心取 `Display.getCutout()` 四边切孔矩形中第一个非空者的中心，
     找不到切孔时回退屏幕顶部中央
   - 只绘制进度弧（12 点方向顺时针，电量 × 3.6°），
     **未充电部分不绘制背景轨道，进度弧以外区域 100% 透明**
   - `ACTION_BATTERY_CHANGED` 广播驱动电量/充电状态，`onSizeChanged`（旋转）时重算圆心

### 为什么注入宿主的类必须是纯 Java

早期版本用 Kotlin 写自绘 Drawable，经注入的类加载器（父 = SystemUI 加载器）加载时，
父委托会把 `kotlin.jvm.internal.Intrinsics` 解析到 SystemUI 自带的旧版 Kotlin 运行时
（无 `checkNotNullParameter`），导致 `NoSuchMethodError`。现所有进入 SystemUI 进程的自绘类
（`CameraRingView`）均为纯 Java；Kotlin 仅保留在模块自身加载器加载的 `MainHook`/`BatteryConfig` 中。

### 防崩溃措施

- Hook 设置 `ExceptionMode.PROTECTIVE`，Hooker 内部逐层 try-catch
- 悬浮窗创建/移除、反射调用均 try-catch，失败只记日志不影响 SystemUI
- `CameraRingView.onDraw()` 整体包裹 try-catch，绘制异常直接跳过该帧
- 模块入口 `onPackageLoaded` 整体 try-catch，并按包名过滤（仅 `com.android.systemui`）


## 构建与安装

1. `gradlew assembleDebug`（或 assembleRelease）
2. 安装 APK，在 LSPosed 中启用模块（作用域已锁定，无需勾选）
3. 重启"系统界面"应用即可生效，**无需重启手机**。任选一种方式：
   - `adb shell killall com.android.systemui`（SystemUI 被杀后会自动重启）
   - 系统设置 → 应用管理 → 显示系统应用 → 系统界面 → 强行停止
   - LSPosed 管理器中该模块的"重启系统界面"入口
4. 在系统设置中隐藏原电池图标（ColorOS 自带功能，隐藏后 WiFi、信号等图标自动补位）
5. 打开模块 App 调整参数

## 注意事项

- 本模块需要支持 **libxposed API 102** 的 LSPosed 版本（API 102 曾为内部测试快照，请确认所用 LSPosed 已支持）
- `RemotePreferences` 在 SystemUI 进程内为只读；若框架不支持远程偏好（embedded 模式），模块会回退默认配置并在日志中提示
- 悬浮窗类型低于钥匙guard层级，**锁屏界面上电量环不可见**（解锁后恢复）
- 打开前置摄像头预览（自拍/视频通话）时电量环会叠在预览画面上，属预期行为
- 找不到摄像头切孔的设备（如无挖孔）会回退绘制在屏幕顶部中央，可用偏移参数微调
- 排查问题：`adb logcat | grep CycleBattery`，关键日志为 `camera ring overlay added`
