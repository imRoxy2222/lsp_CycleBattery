# ColorOS 17 环形电量模块 - 功能说明

## 功能概述

在 ColorOS 17 的状态栏上以自绘"环形电量"接管系统电量图标，并支持用户自定义：

| 功能点 | 说明 | 配置键 |
| --- | --- | --- |
| 启用开关 | 关闭后放行系统原始逻辑 | `enabled` |
| 环形大小 | 10 ~ 48 dp | `size_dp` |
| 水平偏移 | -24 ~ 24 dp（translationX） | `offset_x_dp` |
| 垂直偏移 | -24 ~ 24 dp（translationY） | `offset_y_dp` |
| 线条粗细 | 1 ~ 10 dp | `stroke_width_dp` |
| 普通状态颜色 | 电量正常时 | `color_normal` |
| 充电状态颜色 | 插入充电器时 | `color_charging` |
| 低电量状态颜色 | 电量 ≤ 阈值时 | `color_low` |
| 低电量阈值 | 5% ~ 50% | `low_level_threshold` |

颜色绘制参数（颜色、粗细）为即时生效；大小/位置需等下一次图标刷新（充拔电、锁屏解锁等）或重启系统界面。

## 技术实现

### 依赖与规范

- **libxposed API 102**（`io.github.libxposed:api:102.0.0`，compileOnly）：
  - 入口类注册于 `app/src/main/resources/META-INF/xposed/java_init.list`
  - 作用域静态锁定：`META-INF/xposed/scope.list` 仅含 `com.android.systemui`，且 `module.prop` 声明 `staticScope=true`，用户无法在 LSPosed 中勾选其他应用
  - `module.prop` 声明 `exceptionMode=protective`
- **配置同步**：`io.github.libxposed:service:102.0.0`（RemotePreferences）
  - 模块 App 端通过 `XposedServiceHelper` 连接框架服务后写入
  - SystemUI 进程内通过 `XposedModule.getRemotePreferences()` 只读，并注册监听器实时刷新
- **DexKit**（`org.luckypray:dexkit:2.3.0`）：仅当按类名找不到工厂类（宿主混淆）时启用，按字符串特征 `CircleBatteryContentDrawable` 定位系统圆环类，再按方法签名 `(Context, int, int) -> 圆环Drawable` 定位工厂类
- **宿主类桩**：`stub` 模块（compileOnly）提供 `com.oplus.systemui.statusbar.pipeline.battery.ui.drawable.BatteryContentDrawableBase` 的编译期声明，运行时由 SystemUI 宿主提供真实实现

### Hook 链路（基于 jadx 反编译确认）

ColorOS 17 SystemUI 电量管线：

```
LocationBasedBatteryViewModel
  └─> BatteryViewBinder.bind$updateBatteryIconStyle
        ├─ 按 iconStyle 调整内部 ImageView 尺寸
        ├─ drawable = BatteryContentDrawableFactory.createContentDrawable(context, iconStyle, 0)   ← Hook 点 1
        └─ StatBatteryMeterView.setBatteryStyleDrawable(drawable)                                  ← Hook 点 2
              └─ 内部 ImageView.setImageDrawable(drawable)
  └─> BatteryViewBinder.bind$updateBatteryContentView
        ├─ setChargeIconId(id)   → id > 0 表示充电中
        ├─ setBatteryLevel(level)
        ├─ setSpecialColor(...)
        └─ setColors(progress, background, tint)  → 本模块忽略，改用用户配置
```

1. **Hook 点 1（工厂）**：返回自绘 `RingBatteryDrawable`（继承宿主 `BatteryContentDrawableBase`，模块 APK 经 `PathClassLoader(父=SystemUI加载器)` 注入），跳过 `proceed()` 时不产生系统对象
2. **Hook 点 2（视图）**：拿到 `StatBatteryMeterView`，在子树中找到持有 RingBatteryDrawable 的 `ImageView`，按配置写入 `layoutParams.width/height` 与 `translationX/Y`；同时记录 WeakReference 供配置变更时重放

### 防崩溃措施

- 所有 Hook 均设置 `ExceptionMode.PROTECTIVE`
- Hooker 内部逐层 try-catch：任何异常回退到 `chain.proceed()`（系统原始行为）
- `RingBatteryDrawable.draw()` 整体包裹 try-catch，绘制异常直接跳过该帧
- 模块入口 `onPackageLoaded` 整体 try-catch，并按包名过滤（仅 `com.android.systemui`）

## 构建与安装

1. `gradlew assembleDebug`（或 assembleRelease）
2. 安装 APK，在 LSPosed 中启用模块（作用域已锁定，无需勾选）
3. 重启手机（或重启系统界面：`adb shell killall com.android.systemui`）
4. 打开模块 App 调整参数

## 注意事项

- 本模块需要支持 **libxposed API 102** 的 LSPosed 版本（API 102 曾为内部测试快照，请确认所用 LSPosed 已支持）
- `RemotePreferences` 在 SystemUI 进程内为只读；若框架不支持远程偏好（embedded 模式），模块会回退默认配置并在日志中提示
- 环形绘制以"背景轨道 + 进度弧"呈现：轨道为当前状态色 20% 透明度整圆，进度弧自 12 点方向顺时针
- 修改大小/位置后若未立即生效，等待图标刷新即可；彻底生效可重启系统界面
