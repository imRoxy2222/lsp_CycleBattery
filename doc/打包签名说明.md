# 打包签名说明

## 密钥信息

| 项目 | 值 |
| --- | --- |
| 密钥库文件 | `keystore/cyclebattery.jks` |
| 别名（alias） | `cyclebattery` |
| 算法 | RSA 4096（SHA384withRSA） |
| 有效期 | 100 年（36500 天） |
| 密码 | 见 `keystore.properties`（store 与 key 密码相同） |
| 证书主体 | CN=ColorOS17CycleBattery, OU=Personal, O=imroxy2222, C=CN |

> 本项目为私有仓库，密钥与 `keystore.properties` 均随仓库提交，**未**加入 `.gitignore`。

## Gradle 接入方式

- `app/build.gradle.kts` 读取根目录 `keystore.properties`：
  ```properties
  storeFile=keystore/cyclebattery.jks
  storePassword=...
  keyAlias=cyclebattery
  keyPassword=...
  ```
- `signingConfigs` 创建名为 `module` 的配置，同时应用于 **debug** 与 **release** 构建
  （两个构建类型同签名，可直接互相覆盖安装，无需先卸载）
- 若 `keystore.properties` 不存在（如 CI 拉取后未附带密钥），构建仍可进行：
  release 回退为未签名，debug 回退为默认 debug 签名

## 版本号规则

| 项 | 规则 |
| --- | --- |
| `versionName` | 固定 `1.0` |
| `versionCode` | **当前分支提交 commit 数**（`git rev-list --count HEAD`），构建时自动读取 |

- 实现位于 `app/build.gradle.kts`：`CommitCountValueSource`（Gradle `ValueSource`），
  与配置缓存兼容——commit 数变化时 Gradle 自动失效缓存并重新取值
- 每次提交后重新打包，versionCode 自动 +1，可直接覆盖安装升级
- git 不可用（未初始化仓库/无 git 命令的环境）时回退为 `1`，保证构建永不因版本号失败
- `minSdk = 35`（Android 15）；代码本身无厂商私有依赖，降 minSdk 仅放宽安装门槛

## 常用命令

```bash
# 构建（产物：app/build/outputs/apk/release/app-release.apk，已签名）
gradlew assembleRelease

# 查看证书信息
keytool -list -v -keystore keystore/cyclebattery.jks -alias cyclebattery

# 校验 APK 签名
apksigner verify --print-certs app/build/outputs/apk/release/app-release.apk
```

## 换机/重建密钥

签名一旦发布就不要更换，否则用户必须卸载重装（Xposed 模块配置会丢失）。
请妥善备份 `keystore/` 目录与 `keystore.properties`。
